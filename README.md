# SA Simple Will

A working UX prototype for a guided, flat-fee South Australian simple-will service.

## V1 includes
- suitability / complexity screening
- will-maker details
- family details
- executor and backup executor
- guardian nomination
- asset-category checklist
- specific gifts
- residuary beneficiaries
- substitute-beneficiary instructions
- rules-based Will Health Check
- final review screen
- browser-only draft saving

## Legal status
This is a prototype, not a production legal-document service. The operative will clauses, legal decision rules, document generation, signing workflow and customer disclosures must be reviewed and approved by a suitably qualified South Australian solicitor before commercial release.

The prototype deliberately does **not** generate a purported final will.

## Data
No backend is connected in V1. Answers are stored in the user's browser using localStorage.

Do not enter real client data during prototype testing.

## Deployment
The project is deliberately static for the first UX test and can be deployed to Netlify without a build command.
